# Quick Start

## For New Projects

You have two options:

1. **Use the local minimal example project** in this repository:
   - Open `res://example/project.godot` in Godot 4.4+.
   - Run the project (`example/main.tscn`).
   - Controls include:
     - `WASD` move, `E` interact
     - `F5` quick-save
     - `F9` quick-load
2. **Use [the template](https://github.com/SlashScreen/skelerealms-template)** for a separate starter repository.

## For Existing Projects

Use this repo as a submodule in your addons folder.
